# AAAA-ST-Image-Cleaner（Image Cleaner）

酒馆（SillyTavern）聊天图片净化插件：一键**去除图片自带信息**（文生图画师串 / EXIF / PNG tEXt / XMP 等全部元数据），支持下载与复制两种输出方式。

> 核心原理：不是简单换格式，而是把图片 **Canvas 重绘**（重新绘制像素后导出），重绘产物**不含任何元数据**，画师串等信息从根源上被剥离。

---

## 功能一览

| 功能 | 说明 |
|------|------|
| 🖼️ 下载净化图 | 按钮或右键菜单，输出 **WebP**（默认）/ PNG，已剥离全部元数据 |
| 📋 复制净化图 | 按钮或右键菜单，输出 **PNG**（Chromium 剪贴板仅支持 PNG），同样已净化 |
| 🗂️ 下载/复制原图 | 右键菜单可直接获取**带元数据的原始图片** |
| 🎚️ 自定义右键菜单 | 右键任意酒馆图片弹出插件菜单，替代浏览器原生「另存为」 |
| ⚙️ 设置面板 | 总开关、输出格式（webp/png）、质量（0~1）、失败回退开关 |
| 🔒 失败回退 | 跨域/CORS 等净化失败时，可选自动回退下载原图并弹提示 |

## 安装

1. 将整个 `AAAA-ST-Image-Cleaner` 目录复制到酒馆的：
   ```
   public/scripts/extensions/third-party/AAAA-ST-Image-Cleaner/
   ```
2. **重启酒馆**（或刷新浏览器页面）让插件加载。
3. 在扩展管理面板中确认插件已激活（显示为「Image Cleaner」）。

### 文件结构

```
AAAA-ST-Image-Cleaner/
├── manifest.json   # 扩展清单（入口、样式、加载顺序）
├── index.js        # 插件主逻辑（净化、右键菜单、设置 UI）
├── style.css       # 插件样式（右键菜单、设置面板，前缀类隔离）
└── README.md       # 本文档
```

## 使用方法

### 1. 消息图片悬浮控制栏按钮

把鼠标悬停在聊天消息的图片上，控制栏会出现两个新按钮：

- **⬇️ 下载**（fa-download）：下载净化图（默认 WebP）
- **📄 复制**（fa-copy）：复制净化图到剪贴板（PNG）

### 2. 自定义右键菜单

**右键点击任意酒馆图片**（聊天图、文生图渲染图、头像、大图预览弹窗、表情图等），弹出插件菜单：

```
⬇️ 下载原图
📋 复制原图
──────────────
✨ 下载净化图
📋 复制净化图
```

- **下载/复制原图**：原样获取原始文件（保留画师串等元数据）
- **下载/复制净化图**：Canvas 重绘后输出（元数据已剥离）
- 点菜单以外任意处 / 按 `Esc` / 滚动页面，菜单自动关闭

> 菜单覆盖全页面所有实义 `<img>`，包括大图预览弹窗（`<dialog>` 顶层）内的图片；自动过滤 1px 占位 gif、无图占位符等装饰图。

### 3. 设置面板

在扩展管理界面（魔法棒 → 扩展管理）展开 **「Image Cleaner 净化设置」**：

| 设置项 | 说明 |
|--------|------|
| **启用插件** | 总开关；取消勾选后右键菜单、悬浮按钮、所有事件全部失效（恢复浏览器原生右键） |
| **跨域/失败时回退下载原图** | 净化失败（如 CORS）时自动下载原图并弹出黄色提示 |
| **输出格式** | WebP（默认，体积小）/ PNG（保留透明通道） |
| **质量** | 0.1 ~ 1.0（WebP 有效，默认 0.9） |

> PNG 与 WebP 输出**均可去除画师串等元数据**（Canvas 重绘剥离），只是格式不同。

## 技术原理

### 净化流程（画师串如何被去除）

```
原始图片 → fetch → Blob → HTMLImageElement（crossOrigin=anonymous）
        → Canvas drawImage 重绘像素 → canvas.toBlob(type, quality) → 净化图
```

- **Canvas 重绘 = 像素级重建**：导出的新图片只含像素数据，EXIF、PNG tEXt、XMP、画师串、ICC 配置等一切元数据区块全部丢弃。
- **与格式无关**：无论输出 WebP 还是 PNG，都经过重绘，净化效果一致。

### 边界处理

| 场景 | 处理方式 |
|------|---------|
| **透明 PNG** | `hasTransparency()` 像素采样检测（alpha < 250，避免误判抗锯齿边缘）；透明图自动输出 PNG（WebP 不支持透明） |
| **动图（GIF/APNG）** | Canvas 只能取首帧，自动提示「动图已取首帧」 |
| **跨域/CORS** | 净化失败时按设置回退下载原图，并弹提示区分 |
| **剪贴板限制** | Chromium 系浏览器 `navigator.clipboard.write()` 只接受 `image/png`，故复制固定输出 PNG（已实测验证） |

### 为什么不用「原生右键另存为」？

浏览器原生右键的「将图片另存为」由浏览器接管，保存的是**原始文件**（画师串仍在），且 JS **无法拦截或改写**该动作。因此插件拦截 `contextmenu` 事件弹出自己的菜单，接管下载/复制流程。

### 右键菜单的技术要点

- **事件委托**：`$(document).on("contextmenu", "img", ...)` 委托到 document，无论图片由酒馆核心还是任何第三方插件渲染都能命中。
- **关闭机制**：用 document **捕获阶段**监听 `mousedown/touchstart/contextmenu` 关闭菜单，不受酒馆中间元素 `stopPropagation` 影响（点菜单外必关）。
- **dialog 顶层适配**：大图预览弹窗是 `showModal` 打开的 `<dialog>`（top layer），菜单挂进 dialog 内部才不被遮挡。
- **占位图过滤**：过滤空 src、`data:,`、1px 透明 gif（懒加载占位）、No-Image 占位符、头像裁剪框底图，避免误伤。

## 兼容性

- 依赖酒馆全局 `SillyTavern.getContext()` 与 jQuery（酒馆自带）。
- 需浏览器支持 Canvas `toBlob`、`ClipboardItem`（现代 Chrome / Edge / Firefox 均支持）。
- 剪贴板写入需要浏览器授予权限（HTTPS 或 localhost 环境，酒馆本地运行默认满足）。

## 常见问题

**Q：复制出来是 PNG 而不是 WebP？**
A：Chromium 系浏览器的剪贴板 API 只接受 `image/png` 一种图片格式（已实测），这是浏览器安全限制，前端无法绕过。需要 WebP 请用「下载净化图」按钮。

**Q：净化后图片变大了？**
A：WebP 通常比原 PNG 更小；若原图本身是高质量 JPEG 且未开启透明，WebP 体积也接近。设置里可调低质量（0.5~0.8）进一步压缩。

**Q：跨域图片下载失败？**
A：跨域图片若无 CORS 头，Canvas 会被污染导致净化失败。开启「跨域/失败时回退下载原图」可自动改下原图（会弹提示说明）。

**Q：右键菜单没反应？**
A：检查设置面板「启用插件」是否勾选；确认插件已在扩展面板激活（无红色 warning）。
